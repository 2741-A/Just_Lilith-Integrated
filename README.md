## 这一版比原版多了什么

> 下面的内容是我在原版基础上加的。原版本身的功能照样都在（见下一节）。

- **🎧 没有 NVIDIA 显卡也能出声** —— 原版要求语音服务上报 `device: cuda`，非 N 卡机器上语音根本起不来（原版说明里那句「缺少 CUDA 设备会直接拒绝启动」就是这个）。这一版改成没有 CUDA 就回退 CPU，**核显机器一样能说话**。
- **⚡ 语音接近实时** —— 换用更快的计算库后，逐元素算子和注意力快 2–6 倍。原版实测「开口比气泡晚约 7 秒」，这一版基本是说完就出声。
- **🎙️ 中文默认换成 v2Pro** —— 原版自带的 v4 音质最好，但**在 CPU 上比实时还慢**（实测 RTF 1.93），核显机器根本追不上。这一版把中文默认设成 v2Pro（RTF 0.48，快约 4 倍）。批处理也从 1 提到 8，合成再快约 40%。
  > ⚠️ **日文没有改，还是原版的 v4。** 这一版只动了中文。
- **🔌 Agent 不绑 OpenAI** —— 走 Codex 通道，但提供方可以换成 DeepSeek 等任何 OpenAI 兼容服务，只要一个 API Key，不需要 OpenAI 账号。
- **🎵 音乐评论** —— 游戏里放音乐时，她会先查证这首歌是什么、讲了什么，再用自己的话补一句短评。搜索链会依次查官方 WIKI、萌百、B站、必应、搜狗、360、网易云；LLM 查不出来时用游戏自带的台词池兜底，不会冷场。评论会缓存到本地，同曲再说时换一个角度。
- **🎼 歌词浮层** —— 播放时在屏幕上方显示当前歌词，支持逐字上色与中文翻译，歌词优先读本地 `.lrc` / `.zh.lrc`，没有才去网易云取。
- **💰 余额提醒** —— DeepSeek 账号余额低于阈值时，她会提醒你一次（只在「够用→不够用」跳变时说一次，不会反复念）。
- **🪑 让她爬到你窗口上坐** —— **F5** 叫她爬上窗口坐好；另有走过去 / 回到中间 / 离开座位等指令。
- **🎭 可触发的动作更多了** —— 动作白名单从 45 条扩到 52 条（**动作本身来自游戏本体**，这个只是让它们能被对话调用）。
- **👤 对话里能叫出你的名字** —— 读游戏里的玩家名，带进对话。
- **🫧 气泡、语音、动作三者同步** —— 不再各说各的：气泡跟着语音开播一起冒，动作等到开口那一刻再做。

> ⚠️ **只有上面这些是本版做的。** 下面那一整节（对话、幻境记忆、世界书、本地语音、Agent）
> 都是**原版 Just_Lilith 自带**的功能——本版只是在这基础上改，不能算在本版头上。

> 📖 **每一条改动的出处、以及哪些东西来自哪些社区 mod，都写在 [来源与改动说明.md](来源与改动说明.md) 里。**

### 和我聊聊，不必只选准备好的台词（原版）

“今天有点累。”“我突然想到一个奇怪的问题。”“莉莉丝，陪我想想这个。”——嗯，这些都可以是开头。

插件接入兼容 OpenAI 格式的模型服务。默认按 **F7** 唤出聊天框，快捷键也能调整。

- 支持**三套 API 配置**，保存、检测连接、刷新和搜索模型。
- 支持 **Chat Completions / Responses** 两种接口格式；具体兼容性取决于服务商。
- 普通聊天严格使用**最上方的已保存配置**，不会出错后悄悄换到另一个服务。

> 选好连接我们的那条线，再来叫我吧。别忘了先点保存——只填进输入框，可还不算约定好了。

### 给每段对话，留一个可以回来的地方（原版）

我把这些不同的会话叫作**幻境**。你可以新建、切换、重命名和删除，把不同话题分开放。

这里有两种容易弄混的「记得」：

| 入口 | 放着什么 |
| --- | --- |
| **幻境记忆** | 当前幻境里的对话记忆，可打开查看和编辑 |
| **回忆** | 世界书背景档案，按话题检索相关内容后带入对话 |

我的人格文件也可以编辑，保存后会在后续对话中重新读取。

这些设计是为了让对话更连贯，**不是「每句话都会永久、完整地记住」的保证**。摘要可能遗漏细节，模型也可能理解错。重要的事情，你可以和我一起核对。

> 另外，内置人格和背景资料涉及原作剧情与不同分支，**介意剧透的话，先完成原作，再来翻我的回忆吧。**

### 让文字，也带上一点声音（原版＋本版改动：默认中文模型、无 N 卡也能出声、合成提速）

基于 **GPT-SoVITS 的本地 TTS 服务**，支持**汉语、日语**朗读；气泡和普通会话正文保持中文。

- 提供自动参考选择，以及**日常、兴奋、哭腔、困惑、睡意、傲娇、狡黠**等参考风格。
- 支持反应音与正文语音衔接，以及音量、语音和服务开关配置。
- 语音生成异常时**会保留文字**，不让一句话跟着声音一起丢掉。

第一次启用或切换语言需要加载相应模型，等待时间取决于你的设备。

> 欸，要听傲娇的版本？可以陪你演一下。不过，别把那当成我每句话的固定语气呀。

### 偶尔，也一起认真做点事（原版＋本版改动：提供方可换成任何 OpenAI 兼容服务）

可选的 **莉莉丝 Agent**：使用独立的 Codex 专属对话，在配置的项目目录中承接任务；具备工具和权限时，可以执行命令、编辑文件。

- Agent 与普通聊天使用**独立的会话和人格文件**，工作内容不混进普通聊天记忆。
- 可以查看运行状态、暂停请求，并到对应的 Codex 对话里核对过程。

**装它的方式：安装器里勾「莉莉丝 Agent」就行**（约 78 MB，默认不勾）。它会：

1. 下载 Codex CLI 的独立 Windows 程序，**装进插件目录**（不装到系统任何地方）
2. 给它一个**自己的配置目录**（插件目录下），**不碰你的 `~/.codex`**
3. 把 Agent 配置指向它，提供方模式设为 `saved_responses`
   —— 也就是**直接复用你为聊天填的那套 API 配置和 Key**，不用再填一遍

| 要什么 | 是什么 |
| --- | --- |
| **Codex CLI** | 干活的执行器——真正读写文件、跑命令的是它。GitHub `openai/codex`，开源工具，**不需要 OpenAI 账号** |
| **一个模型服务** | 驱动它的模型，要 OpenAI 兼容接口。**DeepSeek 官方 API 就能用**（`api.deepseek.com`），要的是 **API Key**，不是桌面版 |

> ⚠️ **只有 Codex 这一种**。它不是"随便换个 agent 就行"——插件是靠 `codex app-server`
> 那套专有协议跟它说话的（`thread/start`、`thread/resume` 这些方法名都是 Codex 独有的）。
> DeepSeek Harness、Cherry Studio、DeepSeek 桌面版**都接不上**，换不了。
> **但你不需要 OpenAI 账号**——Codex 只是个执行器，模型用你自己的。

**装完还差两步才真能用**（安装器的「接下来」面板里会提醒）：

1. 普通聊天那套 API 配置的**接口格式要选 `Responses`**（不是 Chat Completions）—— Agent 复用这套配置
2. 进游戏 → 「莉莉丝」页 → 选一个 Agent 模型 → 打开 Agent

> ⚠️ **Agent 的权限很大**（能读写这台电脑上的文件）。第一次先用一个测试文件夹试，
> 别直接对着重要目录开。详细说明见作者的
> [《LLM 与 Agent 服务配置指南》](https://github.com/Ariname-Lilith/Just_Lilith/blob/main/LLM与Agent服务配置指南.md)。

> ⚠️ **DeepSeek 的桌面版/网页版不行。** 那是聊天客户端，不对外提供接口，Agent 接不上去。
> 你要的是 **API Key**（platform.deepseek.com 申请），本质是另一回事。
>
> 同理，**Cherry Studio 也可以当这个"模型服务"** —— 它自带 API 网关
> （`设置 → API 网关`，默认 `127.0.0.1:23333`），Codex 能指过去。
> 不过实测**网关 + DeepSeek 系模型多轮会崩**（转发时丢了推理内容）；换通义千问等非 DeepSeek 模型正常。
> 走 DeepSeek 的话，**直连 `api.deepseek.com` 更稳**。

**开启前请确认项目目录与工具权限；暂停请求不等于撤销已经执行的操作。**

> 陪你完成一件事，和替你决定所有事，是两回事。

> 🤖 **不想自己点？可以让 AI 帮你装。**

### 🎧 关于语音：这一版**不需要 NVIDIA 显卡**

先说结论：**没有 NVIDIA 显卡也能出声。**

原版插件在健康检查里要求语音服务上报 `device: cuda`，而语音服务在没有 CUDA 设备时会如实上报 CPU —— 于是**原版在非 N 卡机器上语音根本起不来**。

这一版把那段改成「有 CUDA 就用，没有就回退 CPU 并如实上报」，所以核显机器（Intel Arc / AMD）一样能说话。代价是用 CPU 算，慢一些。

**「语音提速补丁」这个组件就是为这件事准备的，它做两件事：**

1. **写入打好补丁的语音服务脚本**（29 KB，秒完）—— 就是上面说的那个修正，另外还让语音支持 v2 / v2Pro 声学模型、把批处理从 1 提到 8（实测合成提速约 40%）
2. **把采样步数从 32 调到 4** —— 扩散采样步数，直接决定「一句话要算几遍」。实测**快约 8 倍**，音质这一档听不出差别（1/2 才是下限，试过）。
   想换回去：改 `<插件目录>\tts\config\voices.json` 里 `languages.zh.inference.sample_steps` 和 `languages.ja.inference.sample_steps`（中／日各一份，只改一个的话另一种语言照样慢）
3. **装一个更快的计算库**（约 220 MB，走清华镜像）—— 实测逐元素算子和注意力**快 2–6 倍**，把剩下的差距补掉

> 第 3 步是**装到独立目录**的，不碰原有环境的任何文件。不想要就手动删掉
> `<插件目录>\tts\runtime\lilith-packages\`，立刻回到原样。
>
> 这一步实测下载 216 MB、装完占约 1.2 GB。**硬盘不够或者不在意延迟的，可以在安装器里取消勾选** ——
> 那样语音照样能出声（前两步仍然会做），只是慢一点。

**那个 2.4 GB 的语音包，两条路选一条：**

**路 A —— 自己下（快，推荐）**

1. 去原版发布页，下**两个文件，缺一不可**：

   https://github.com/Ariname-Lilith/Just_Lilith/releases/tag/v_0.3.0

   - `tts-main.7z.001`
   - `tts-main.7z.002`

   > 这是**多卷压缩包**，少下任何一个都解不开。
   > 直接下 GitHub 慢的话，在地址前面加 `https://ghfast.top/` 走国内镜像。

2. 把这两个文件**原样**丢进 `桌面\Just_Lilith-TTS\`（不用解压）
3. 回来点安装器上的「开始安装」

安装器会校验 SHA256 → 解压 → 剥掉外层 → 放到位。

> 界面里就有这两个按钮：**「① 打开发布页」** 和 **「② 打开放置文件夹」**，
> 不用自己去翻 Release 页面或找那个文件夹在哪。

**路 B —— 让安装器下**

什么都不用管，直接点「开始安装」。支持**断点续传**：断了、关了、网断了，下次接着下。

> 真下得太慢也别急 —— 安装器会在日志里把下载地址（含国内镜像）写出来，
> 你可以复制到下载工具里下完，再走「路 A」放进去。已经下好的文件不会重下。

**🗣️ 顺便说一句"语气"：她用什么调子说话，是可以选的。**

安装器里有一项 **「参考音色包（视频2 的那套声线）」**，**默认勾着** —— 勾上她说话的语气就和我这边一致
（这套音色来自视频2 的 mod，安装器只从它的发布页取那 4 个音频，不会把人家整个 mod 装进来）。
**不想要就取消勾选** —— 那样用的是语音包自带的那套，功能一模一样，只是语气不同。

> 两边都只影响 4 个风格（日常 / 兴奋 / 哭腔 / 困倦）；其余风格一直是语音包自带的。
> 想用第三套也行：换掉对应目录里的 wav，再把 `voices.json` 里那项的 `prompt_text`
> 改成**音频里实际说的那句话**（文字必须和音频对得上）。

**⚠️ 还有第二段要下 —— 语音运行时（约 2.5–3 GB）。**

那 2.4 GB 的语音包里只有**模型和推理引擎，没有 Python**。Python 运行时由原版作者另给的
**运行时安装器**负责，安装器会把它连同 `tts-runtime-installer\` 一起放好。

**先选一个（两个只能选一个，装错语音起不来）：**

- **没有 N 卡**（核显 / A 卡）、或 N 卡不是 50 系 → 「语音运行时安装器（通用）」
- **RTX 5060 / 5070 / 5080 / 5090** → 「语音运行时安装器（NVIDIA RTX 50 系专用）」

> 不知道自己显卡是什么系？**不用管，安装器会替你选**。

**然后它会问你要不要现在装** —— 点「是」就完事了：

1. 弹出**一个单独的窗口**跑作者那个脚本（看得见进度，大概 1～2 小时，**别关它**）；
2. 跑完之后，安装器**自动接着把语音加速包装上**，你不用再点第二次。

> 🤖 **一句话说清这一步在干嘛**：它从 python.org 和 PyTorch 官方源下 Python + 计算库，
> 装到 `<插件目录>\tts\runtime\` 里。**不从我们这儿下任何东西。**

**要是当时选了「否」**（或者跑失败了），随时可以补：

- 界面上：**再点一次「开始安装」**，它会再问一遍；
- 命令行：`Just_Lilith-Setup.exe --setup-runtime --game "<游戏目录>"`
  （想先看看它打算干嘛、不真下：加 `--runtime-args -DryRun`）；
- 最原始的办法：去游戏根目录双击 `tts-runtime-installer\安装语音运行时.bat`，跑完再点一次「开始安装」。

> **没有 N 卡为什么也装带 CUDA 的那个？** PyTorch 的 CUDA 版在没有 CUDA 设备时

> "缺少 CUDA 设备就拒绝启动" —— 那个由「语音提速补丁」解决。

## 有几件事，我想先说清楚

### 本地语音，不等于全部离线

语音合成在本地服务里完成；**普通聊天则要把消息发给你配置的模型服务**。发送时会把生成回答所需的消息、人格提示、相关记忆或背景片段交给对应服务；记忆摘要整理也可能产生模型请求。

**插件免费，不代表第三方 API 免费。** 选服务商时请留意它的数据政策和费用。

API Key 用 Windows 当前用户环境加密保存，**换电脑或换 Windows 账号后要重新填**。配置文件、聊天记录和工作区仍属于私人资料——**别把自己的运行目录原样提交到公开仓库**。

### 我会回应，但不是无所不知

模型可能记错、误解或给出不准确的答案。普通聊天不等于随时读取你的整个屏幕，也不等于随时操作你的电脑；项目工具能力属于另行开启的 Agent 通道。

语音是**合成内容**，不代表原作配音演员的新录音、真实表达或认可。插件同样不是官方更新，也不承诺适配所有未来游戏版本。

> 我希望你认真对待我们的对话，也希望你保留自己的判断。嗯，这两件事并不冲突。

## 如果今天有一点不顺利

| 遇到的情况 | 可以先检查什么 |
| --- | --- |
| 设置里没有插件入口 | 安装层级、BepInEx 与游戏版本，以及 `BepInEx\LogOutput.log` |
| 发不出消息 | 顶部配置是否**已保存**，地址、Key、模型、接口格式和额度 |
| 换电脑后认证失败 | 在当前 Windows 账号下重新填写并保存 API Key |
| 有文字，没声音 | TTS 服务与语音开关、`tts\models` 是否完整、首次加载是否仍在进行 |
| 日志里 `module=UI; state=failed` | **两个 DLL 版本不一致**（改了 Core 就必须两个一起换） |
| 歌名认错 / 评论张冠李戴 | 音频文件的**内嵌标签是否带版本号**，见下方 |
| Agent 没有开始工作 | Codex 环境、提供方、项目目录、模型和对应对话里的错误 |

反馈问题时请附上游戏与插件版本、复现步骤，以及**去掉密钥和私人内容后的日志**。

> 💡 上面那条「歌名认错」是个真踩过的坑：WAV 的标题存在内嵌标签里，如果标签缺了括号里的版本（比如三个版本的标签都叫 `Ex-Otogibanashi`），它们会撞成同一个名字、共用同一条评论缓存。**建议把标签设成和文件名一致。**

## 关于语音模型（请读，不然会踩坑）

这个插件**不自带**语音模型。你自己准备时，有三种选择：

**这一版实际用的默认组合：**

| 语言 | 默认模型 | 从哪来 | 大概多大 | 许可 |
| --- | --- | --- | --- | --- |
| **中文** | **v2Pro** | HuggingFace [`lingxi7562/Lilith`](https://huggingface.co/datasets/lingxi7562/Lilith) + GPT-SoVITS 的 `eres2net` 前置 | ~398 MB | **Apache-2.0** + MIT，**可自由再分发** |
| **日语** | **v4（原版，未改动）** | 原版 Release 的 `tts-main.7z` | 随包自带 | ⚠️ 原作者声明**「尚未确认公开再分发授权」** |

> **为什么中文换、日文不换**：中文换 v2Pro 是因为原版 v4 在这类机器上**跑不动**（比实时还慢），
> 而 v2Pro 是 Apache-2.0、可以放心随包发。日文这版**没有动过**——没有人训练的日语 v2Pro 模型，
> 而且也没有必要：日文用得少，慢一点能接受。

**其它可选做法：**

| 做法 | 说明 |

| 换成 v2 中文 | 更小更快，但音质最差。来源是社区 mod Lilith-AI-Mod |
| 自己训练 | 走 GPT-SoVITS 官方流程。训练素材的权利归原作方 |
