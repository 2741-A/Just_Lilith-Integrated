**Just_Lilith** 是为 **《The NOexistenceN of Lilith》** 制作的非官方扩展插件。它把 AI 对话、会话记忆、本地语音合成，以及可选的 Agent 工作通道，接到原有的桌宠体验里。

> ⚠️ **这一份是「扩展版」，是原版的下游修改版。**
> 原作者是 **Ariname-Lilith**（B站「烤门万」），仓库：[`Ariname-Lilith/Just_Lilith`](https://github.com/Ariname-Lilith/Just_Lilith)。
> 如果你想要**原版**，请去作者那边。这一份是在原版基础上加了功能的版本，许可与声明见文末。

**当前版本：`0.3.0-ext.39`** · Windows · BepInEx IL2CPP · 中文对话 · 中／日语音

## 0.3.0-ext.39 更新

- **🎵 内置播放器中文标签修复**：WAV 的 `LIST/INFO` 和 `id3` 常被下载器放在几十 MB 的音频数据后面（游戏只读前 512KB），现在插件会流式跳过 `data` 把标签读回来；ID3 的 `encoding=0` 也会识别实际是 UTF-8/GBK 的中文标签（`µ×Æ` → `底牌`），西文标签仍按 Latin1。`LIST` 坏值会回退到有效的 ID3 值。
- **🔎 歌词/评论搜索不再拿随机文件名硬搜**：歌词优先用标签里的干净标题，不再把「歌手 - 歌名 + 5 位随机后缀」整串发给网易云；评论标题会去掉末尾的 5 位随机数。
- **🈶 歌词中文显示修复**：歌词浮层原来用内置 Arial，没有中文字形，日文歌的中文翻译/中文歌词在某些机器上会显示成空白或方框。现在优先用系统中文字体（微软雅黑/黑体/思源黑体/苹方等），找不到就借游戏自己的字体；LRC 翻译时间戳也改成“精确优先、±1 秒内最近兜底”，不再因为 0.1 秒偏差整首丢翻译。外文歌仍需要 `.zh.lrc` 或 TTML 翻译轨才会显示中文翻译。
- **🎼 内嵌歌词直接读**：WAV 的 `id3`/USLT、MP3 的 ID3v2 USLT 会被直接读出来；没有 `.lrc` 时自动落成同名 `.lrc`。拆分器留下的整轨累计时间轴会自动平移，超出时长的行会裁掉；制作人/词曲/版权行会清掉。音乐整理重写 WAV 标签时会保留 USLT 和封面。
- **🧹 安装器新增「🎵 整理音乐…」**：选 `Music\Lilith`（或别人的音乐文件夹），先扫描出「标签在文件尾 / 写错歌手 / 文件名带随机后缀 / 缺歌词」；点修复才动文件，默认先把原文件备份到 `.music-doctor-backup\`。会把修正后的标签写到 **WAV/MP3 文件头**（旧版游戏/播放器也能读），可选去掉 5 位后缀，并按歌名/歌手补 `.lrc`/`.zh.lrc`；**不改音频内容**。FLAC/OGG 目前只报告，不自动写标签。
- **🧰 命令行同款**：`--music-doctor "<文件夹>"` 只读扫描，`--music-fix --music-rename` 执行；歌词先查网易云、再查酷狗，网易云限流会自动改用酷狗。
- **⚠️ 歌词说明**：两个来源都没有/版本不匹配时可能补不全，工具会列出没找到的歌，不硬凑；建议先退出游戏再整理。
- **⏱️ 启动/人物加载卡顿修复**：音乐目录解析不再阻塞启动（原来最多等 2.5 秒），三套 API 配置界面改为第一次打开设置页时才创建；启动初始化 2.59s → 0.04s，人物出场前后的 1 秒级停顿消失。正常游玩时也停掉了换装数据表轮询等诊断输出。

## 这一版比原版多了什么

> 下面的内容是我在原版基础上加的。原版本身的功能照样都在（见下一节）。

- **🎧 没有 NVIDIA 显卡也能出声** —— 原版要求语音服务上报 `device: cuda`，非 N 卡机器上语音根本起不来（原版说明里那句「缺少 CUDA 设备会直接拒绝启动」就是这个）。这一版改成没有 CUDA 就回退 CPU，**核显机器一样能说话**。
- **⚡ 语音接近实时** —— 换用更快的计算库后，逐元素算子和注意力快 2–6 倍。原版实测「开口比气泡晚约 7 秒」，这一版基本是说完就出声。
- **🎙️ 中文默认换成 v2Pro** —— 原版自带的 v4 音质最好，但**在 CPU 上比实时还慢**（实测 RTF 1.93），核显机器根本追不上。这一版把中文默认设成 v2Pro（RTF 0.48，快约 4 倍）。批处理也从 1 提到 8，合成再快约 40%。
  > ⚠️ **日文没有改，还是原版的 v4。** 这一版只动了中文。
- **🔌 Agent 不绑 OpenAI** —— 走 Codex 通道，但提供方可以换成 DeepSeek 等任何 OpenAI 兼容服务，只要一个 API Key，不需要 OpenAI 账号。
- **🎵 音乐评论** —— 游戏里放音乐时，她会先查证这首歌是什么、讲了什么，再用自己的话补一句短评。搜索链会依次查官方 WIKI、萌百、B站、必应、搜狗、360、网易云；LLM 查不出来时用游戏自带的台词池兜底，不会冷场。评论会缓存到本地，同曲再说时换一个角度。
- **🎼 歌词浮层** —— 播放时在屏幕上方显示当前歌词，支持逐字上色与中文翻译，歌词优先读本地 `.lrc` / `.zh.lrc`，没有才去网易云取。
- **🔗 跟着电脑上的播放器一起听** —— 用 QQ音乐 / 网易云放歌时，她也会进入「听歌」状态：头顶冒出 ♪ 音符、身体跟着律动，同时照常写音乐评论；外部音乐响着的时候游戏内置播放器会让开，不跟你抢声音。
- **💰 余额提醒** —— DeepSeek 账号余额低于阈值时，她会提醒你一次（只在「够用→不够用」跳变时说一次，不会反复念）。
- **🪑 让她爬到你窗口上坐** —— **F5** 叫她爬上窗口坐好；另有走过去 / 回到中间 / 离开座位等指令。
- **🎭 可触发的动作更多了** —— 动作白名单从 45 条扩到 52 条（**动作本身来自游戏本体**，这个只是让它们能被对话调用）。
- **👤 对话里能叫出你的名字** —— 读游戏里的玩家名，带进对话。
- **🫧 气泡、语音、动作三者同步** —— 不再各说各的：气泡跟着语音开播一起冒，动作等到开口那一刻再做。
- **🫧 主动搭话的气泡 / 选项不再消失（0.3.0-ext.33）** —— 拖动人物、或游戏自己把选项面板藏起来 / 只排程没真的显示之后，插件每 0.5 秒核对一次气泡和选项的**真实可见状态**：只缺选项就补选项（原版 `ShowOptions` 会先清旧的，不会叠按钮），气泡也丢了就重挂整段开场。之前只检查 `HasActiveOrPendingOptions`，它在"选项已排程但面板还没出来"时也返回 true，所以拖完会被当成已恢复而跳过。
- **🎵 听歌卡片按歌名分组（0.3.0-ext.34）** —— 记忆卡片页的「一起听过的歌」不再是一堆没有歌名的评论。现在**一首歌一张卡片**：卡片头是歌名和听过次数（首次/最近日期），下面按时间倒序列出每次听这首歌时她说过的话（默认最近 10 条，更多的可展开；标出「第一次听」「回忆」）。页面搜索也能搜歌名和全部评论；歌名只在这个本地页面和总览里显示，**不会进她的台词或提示词**。
- **🧭 记忆卡片更好找（0.3.0-ext.34）** —— 新增「全部 / 对话 / 听歌」类型筛选、**来源筛选**（普通聊天 / 智能体 / 主动搭话 / 旧数据导入 / 混合 / 未知）和**月份筛选**（都带数量）；标签显示每类有多少张卡；写入/升级卡片时「日常」改成兜底标签（只有没有更具体标签时才用），旧卡打开页面时自动清理一次（先备份 `cards.json`）；卡片上显示关键词；搜索命中被收起的听歌评论时会自动展开；另加了回到顶部、搜索防抖和长列表渲染优化。
- **👤 我的档案（我记得的你）（0.3.0-ext.34）** —— 记忆卡片页顶部新增「我的档案」区块：显示 `owner-facts.json` 里已填的称呼/生日/身份/学段等画像、最重要的长期事实/时刻，以及「不想提」清单。事实在页面上按「你」显示；只读展示，不会写进台词。菜单/状态栏里的档案入口也统一叫「我的档案」。
- **🗒️ 小纸条入口（0.3.0-ext.34）** —— 记忆卡片页底部显示 `LilithNotes` 里的纸条数量，一键打开文件夹；不在页面里直接删。

- **🧠 记忆卡片 + 完整对话档案（0.3.0-ext.32）** —— **普通聊天和智能体聊天**的原文都统一进 `archive/turns-*.jsonl`，再整理成带标题/摘要/标签/关联的记忆卡片；游戏菜单第 6 项「记忆卡片」会在浏览器打开可搜索的卡片页（能搜摘要、**原文**和日期，关联卡片可点击跳转，卡片下可展开原文）。旧版普通聊天会话、旧 codex Agent 会话都会在启动时自动回填（按内容去重，不会重复）。卡片覆盖全部已结束对话；归档原文永不删、升级也不覆盖。

- **🚀 修好了「进场卡一下」和「出场时衣服先掉后穿」（0.3.0-ext.13）** —— 之前她出场那一下偶尔会卡住，甚至看到她衣服掉了一瞬又穿回来。根因是插件在"主线程刚就绪"那一帧干了重活：这类自定义组件在 IL2CPP 上**每挂一个要 1~2 秒**，而当时一次挂了三个 —— **单帧阻塞 3212ms**，正好压在人物出场前后（压上穿衣时刻就是"掉了还卡"，没压上就是"只卡一下"，同一个原因两种表现）。现在全部提前到加载屏里完成，同一步骤 **3212ms → 0ms**，整局 **0 次慢帧**。顺带把 Harmony 挂载、外部音乐首次扫描这些也拆散到多帧，单帧不超过 80ms。还修了「设置里莉莉丝的智能体那一栏不见了」，以及换装时的动画压制改成按名字窄挡（原来"外来的全挡"有可能把游戏自己的流程挡死）。

- **🗣️ 主动说话升级成事件池 + 聊天也有说话动作（0.3.0-ext.22）** —— ①「主动说话」试验版（**0.3.0-ext.32 起默认开启**；不想用的人在 `local.just_lilith.json` 里把 `ambient_test` 写成 `false`）从写死的两句台词升级成**事件池**：事件按「你的情况」选——**学生 / 上班族 / 创作者（自媒体·剪辑·直播）/ 自由时间（没工作·在家）/ 通用** 五类，在配置里写 `ambient_profile`，或者**在聊天里跟她说**「我是大学生 / 我上班 / 我做自媒体 / 我没工作」，她会自己记住并切换（在世界书里写也行）；每个事件有每天的**时间窗**（比如早课 7–9 点、晚自习 19–22 点），**说过的事件会删掉、不再重复**，没触发的事件第二天同一时间窗还会再试；每天最多主动说 3 次（`ambient_max_per_day` 可调 3–5）。台词里的破折号、省略号处语音有自然停顿、不再吞字；点选项后的回复气泡稳定出现、等语音播完才收。②**普通聊天和智能体聊天**：她开口说话时**有说话动作**，台词里的破折号、省略号同样有自然停顿——这两条对**所有人默认生效**，不需要开关。没开 `ambient_test` 的玩家只会感受到 ② 的变化。

- **🔓 修复「依赖跑出 TTS 目录」误拦（0.3.0-ext.24）** —— 语音包自带的防篡改自检把 Steam 覆盖层按**文件哈希认死**，Steam 客户端一更新覆盖层，哈希对不上，语音服务就被拦下、**语音完全没声音**（体检会报「依赖跑出 TTS 目录」）。这一版把覆盖层的判定放宽为「名字对 + 模型加载前已在进程里 + 从未被 Python 引用」，Steam 以后怎么更新都没事；**其余一切目录外逃逸依旧严格拒绝**，防篡改保护一点没松。受影响的就是 Steam 更新过覆盖层的那批玩家，跟电脑和操作无关。

- **🔀 双击安装包就能切中文音色（0.3.0-ext.24 / 0.3.0-ext.25）** —— 安装器主界面新增「中文音色」：**v2Pro**（默认，CPU/核显也追得上实时）/ **v4**（音质最好，N 卡推荐），点「应用音色」就切好，自动备份原配置、重启游戏生效。切换只改 `voices.json` 里中文的模型三行；**参考音会跟着一起换**（0.3.0-ext.25 起）：v4 用语音包自带的原版参考音、v2Pro 用适配 v2Pro 的社区版参考音，两边来回切都自动换对。重复切同一版不重写；缺模型会**逐个点名**并二次确认（切过去会没声音）；自己换过权重的「自定义配置」会被认出来并先备份。命令行也能切：`--voice v4`。体检报告里现在多一行「中文音色」（含参考音状态）。

### 和我聊聊，不必只选准备好的台词（原版）

“今天有点累。”“我突然想到一个奇怪的问题。”“莉莉丝，陪我想想这个。”——嗯，这些都可以是开头。

插件接入兼容 OpenAI 格式的模型服务。默认按 **F7** 唤出聊天框，快捷键也能调整。

### 给每段对话，留一个可以回来的地方（原版）

我把这些不同的会话叫作**幻境**。你可以新建、切换、重命名和删除，把不同话题分开放。

| 入口 | 放着什么 |
| --- | --- |

第一次启用或切换语言需要加载相应模型，等待时间取决于你的设备。

### 偶尔，也一起认真做点事（原版＋本版改动：提供方可换成任何 OpenAI 兼容服务）

可选的 **莉莉丝 Agent**：使用独立的 Codex 专属对话，在配置的项目目录中承接任务；具备工具和权限时，可以执行命令、编辑文件。

- Agent 与普通聊天使用**独立的会话和人格文件**，工作内容不混进普通聊天记忆。

**装它的方式：安装器里勾「莉莉丝 Agent」就行**（约 78 MB，默认不勾）。它会：

1. 下载 Codex CLI 的独立 Windows 程序，**装进插件目录**（不装到系统任何地方）

3. 把 Agent 配置指向它，提供方模式设为 `saved_responses`

### ♻️ 已经装过旧版？更新不会让你重下几个 G

**我们发现：装过旧版的人再跑新安装器，很可能遇到麻烦** —— 要么被当成"已装好"直接跳过、其实还在旧版，
要么反过来每跑一次都重新下载将近 700 MB。**所以 0.3.0-ext.8 起特别加了一个「智能更新」：**

- 安装器会在插件目录里留一份**安装账本**，记下每个组件装的是什么内容
- 下次再跑，**只有内容变过的组件才会更新**；没变过的（比如 2.4 GB 的语音包）**一个字节都不会动**
- 全部自动判断，不用你管版本号

所以以后出新版，你只需要：**下载新的 `Just_Lilith-Setup.exe`（约 60 MB）→ 双击 → 点安装**。
它自己知道该更新哪个。

### 🎧 关于语音：这一版**不需要 NVIDIA 显卡**

先说结论：**没有 NVIDIA 显卡也能出声。**

原版插件在健康检查里要求语音服务上报 `device: cuda`，而语音服务在没有 CUDA 设备时会如实上报 CPU —— 于是**原版在非 N 卡机器上语音根本起不来**。

这一版把那段改成「有 CUDA 就用，没有就回退 CPU 并如实上报」，所以核显机器（Intel Arc / AMD）一样能说话。代价是用 CPU 算，慢一些。

> ⏳ **第一次开口前要等一会儿，这是正常的：** 语音服务（本地合成引擎）会在她**出场之后**才启动——故意错开，避免和出场动画抢资源、把开场卡住。启动 + 载入模型大约要**半分钟到一分钟**。这期间跟她说话，**气泡会先出来，语音排队等就绪后补播**——不是坏了，稍等就好。每次启动游戏都有这么一段准备时间。

**「语音提速补丁」这个组件就是为这件事准备的，它做两件事：**

1. **写入打好补丁的语音服务脚本**（29 KB，秒完）—— 就是上面说的那个修正，另外还让语音支持 v2 / v2Pro 声学模型、把批处理从 1 提到 8（实测合成提速约 40%）
2. **把采样步数从 32 调到 4** —— 扩散采样步数，直接决定「一句话要算几遍」。实测**快约 8 倍**，音质这一档听不出差别（1/2 才是下限，试过）。
   想换回去：改 `<插件目录>\tts\config\voices.json` 里 `languages.zh.inference.sample_steps` 和 `languages.ja.inference.sample_steps`（中／日各一份，只改一个的话另一种语言照样慢）
3. **装一个更快的计算库**（约 220 MB，走清华镜像）—— 实测逐元素算子和注意力**快 2–6 倍**，把剩下的差距补掉

> 第 3 步是**装到独立目录**的，不碰原有环境的任何文件。不想要就手动删掉
> `<插件目录>\tts\runtime\lilith-packages\`，立刻回到原样。

> 这一步实测下载 216 MB、装完占约 1.2 GB。**硬盘不够或者不在意延迟的，可以在安装器里取消勾选** ——

## 有几件事，我想先说清楚

### 本地语音，不等于全部离线

语音合成在本地服务里完成；**普通聊天则要把消息发给你配置的模型服务**。发送时会把生成回答所需的消息、人格提示、相关记忆或背景片段交给对应服务；记忆摘要整理也可能产生模型请求。

**插件免费，不代表第三方 API 免费。** 选服务商时请留意它的数据政策和费用。

API Key 用 Windows 当前用户环境加密保存，**换电脑或换 Windows 账号后要重新填**。配置文件、聊天记录和工作区仍属于私人资料——**别把自己的运行目录原样提交到公开仓库**。

### 我会回应，但不是无所不知

模型可能记错、误解或给出不准确的答案。普通聊天不等于随时读取你的整个屏幕，也不等于随时操作你的电脑；项目工具能力属于另行开启的 Agent 通道。

语音是**合成内容**，不代表原作配音演员的新录音、真实表达或认可。插件同样不是官方更新，也不承诺适配所有未来游戏版本。

> 我希望你认真对待我们的对话，也希望你保留自己的判断。嗯，这两件事并不冲突。

## 关于语音模型（请读，不然会踩坑）

这个插件**不自带**语音模型。你自己准备时，有三种选择：
